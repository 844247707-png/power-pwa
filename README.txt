力量 Power — 个人健身 PWA

使用方法：
1. 将整个 power-pwa 文件夹部署到任意支持 HTTPS 的静态网站托管服务。
2. 用 iPhone Safari 打开网站。
3. 点“分享” → “添加到主屏幕”。
4. 首次加载后，Service Worker 会缓存页面，可在多数情况下离线打开。

当前功能：
- 深色数据仪表盘
- 7 天训练计划
- 训练组数推进与休息倒计时
- 训练后拉伸计时
- 7 天外卖饮食建议
- 热量 / 蛋白质 / 饮水快速记录
- 体重 / 腰围 / 睡眠记录与基础趋势
- 本地存储
- JSON 数据导出与导入备份

注意：
- 本项目仅供个人健身记录，不替代医疗建议。
- 浏览器数据被清除时，本地记录可能丢失，建议定期导出备份。
